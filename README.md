### 🚀 Featured Project

**[Australian ABN / ACN Validation for Odoo 17](https://github.com/vinothkumarkarthikeyan/l10n_au_abn)** &nbsp;·&nbsp; `Python` `Odoo` `Open-Source`

A published Odoo module that validates and auto-formats Australian business identifiers (ABN/ACN) at the point of entry — implementing the official **ATO Modulus 89** and **ASIC check-digit** algorithms, backed by **30+ automated tests** and a **CI pipeline**. Built largely with Claude Code, then deployed, debugged and documented end-to-end.
